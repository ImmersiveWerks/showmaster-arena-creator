ShowMaster Arena Creator (version 0.26.1)
==========================================

Build grandstands for Planet Coaster 2 without Blender.
Languages: Deutsch, English, Français, Español, 中文, 日本語 (top right).

Requirements: Windows 10/11 and Planet Coaster 2 with the Silver Screen DLC.

- Start: Start menu or desktop icon "ShowMaster Arena Creator".
- Six steps on the left, 3D view on the right. Last step: "Save and install into the game"
  (close the game first).
- cobra-tools is included. The program does not need an internet connection.
- Extras: Guest Spawner ("+500 guests" in the game, needs ForgeUtils).
- If the game is not found: Settings > choose the ovldata folder
  (...\steamapps\common\Planet Coaster 2\Win64\ovldata).
- Uninstall: Windows Settings > Apps. Your saved grandstands are kept.
